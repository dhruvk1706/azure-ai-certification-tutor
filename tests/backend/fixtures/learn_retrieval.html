Choose a retrieval approach for grounding

Vector search finds content by meaning: text is converted into embeddings, and a query returns the passages whose embeddings are closest to the query embedding.

Keyword search matches the exact terms in a query, which works well for product codes, names, and other precise identifiers.

Hybrid search runs keyword and vector queries in parallel and merges the results, so it returns both exact term matches and semantically similar passages.

Semantic ranking reorders an initial set of results by using a language model to score how well each result answers the query.

  • An index must be updated when the source documents change, otherwise answers can be grounded on stale content.
